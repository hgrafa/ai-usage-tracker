Mac says it can’t open the app?

AI Usage is not notarized by Apple yet, so the first launch shows a warning that it can’t be verified. The app is safe to run. Allow it once:

  1. Open AI Usage from Applications and dismiss the warning.
  2. Open System Settings and choose Privacy & Security.
  3. Scroll to the bottom, to the Security section.
  4. Next to “AI Usage” was blocked, click Open Anyway, then confirm with your password or Touch ID.

AI Usage opens in the menu bar. You only need to do this once.
